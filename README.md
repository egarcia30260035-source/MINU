# Página de bienvenida MINUSSD

Esta es una página web estática: al abrir `index.html`, se muestra la imagen de bienvenida a pantalla completa.

## Publicar en GitHub Pages

1. Descomprime este ZIP en tu computadora.
2. Crea un repositorio nuevo en GitHub.
3. Sube `index.html` y la carpeta `assets` (no subas solamente el ZIP).
4. En el repositorio, entra en **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
7. GitHub te dará la dirección pública de tu página.

También puedes probarla localmente haciendo doble clic en `index.html`.
